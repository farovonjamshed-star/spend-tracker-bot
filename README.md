# 💰 Telegram Expense Tracker & Web Dashboard

Умный трекер личных расходов, который живёт в Telegram и синхронизируется в реальном времени с интерактивной веб-панелью. Никаких форм и долгих регистраций: **Telegram и есть ваш аккаунт**.

---

## 🚀 Основные возможности

1. **Мгновенный ввод в 1 сообщение**:
   - Напишите боту: `кофе 350`, `такси 900 работа`, `продукты 2400 супермаркет` или `перевод 500`.
   - Сумма и описание считываются автоматически.
   - Категория определяется встроенным анализатором или ИИ (Gemini).
   - Если указана валюта (`$15`, `50 EUR`, `120 сомони`), сумма сохранится в нужной валюте.

2. **Команды статистики в боте**:
   - `/today` — расходы за сегодняшний день.
   - `/week` — итоги за последние 7 дней.
   - `/month` — детальный отчет за текущий месяц по категориям.
   - `/limits` — статус месячных лимитов и предупреждения о перерасходе.
   - `/share` — подключение общего семейного бюджета на двоих.
   - `/export` — выгрузка расходов в CSV для Excel или Google Sheets.
   - `/help` — список всех возможностей.

3. **Веб-панель без пароля**:
   - Вход в один клик из Telegram по кнопке «📊 Открыть веб-панель» (Telegram WebApp / персональная ссылка с безопасным токеном).
   - Расходы по дням (линейный / столбчатый график) и распределение по категориям (круговая диаграмма Recharts).
   - Адаптивный интерфейс, оптимизированный под мобильные экраны и десктоп.

4. **Полное редактирование и удаление**:
   - Из бота: кнопка «🗑️ Удалить» сразу под сообщением о добавленной трате или команда отмены.
   - Из веб-панели: редактирование суммы, категории, даты и удаление в один клик.

5. **Изоляция данных**:
   - Каждый пользователь идентифицируется по `telegramId`.
   - Данные изолированы и не смешиваются.

6. **⭐ Бонусные возможности**:
   - 🧾 **AI-распознавание чеков**: отправьте фото чека магазинов, заправок или банковских переводов (Alif mobi, DC Next, Сбер и др.) — ИИ извлечет итоговую сумму, валюту, магазин и назначит категорию.
   - 💱 **Мультивалютность**: поддержка TJS, RUB, USD, EUR, KZT, UZS, GEL.
   - 📊 **Экспорт в CSV**: выгрузка с поддержкой кодировки Excel (UTF-8 with BOM).
   - 👥 **Общий бюджет на двоих**: объединение расходов с партнером по коду приглашения.
   - ⚠️ **Лимиты по категориям**: установка месячных лимитов с предупреждениями в боте и на графиках.
   - 💻 **Встроенный Telegram-симулятор**: возможность протестировать бота прямо в браузере в панели управления!

## 🛠️ Стек технологий

- **Backend**: Node.js, Express, TypeScript, tsx, Google Gemini API (@google/genai).
- **Frontend**: React 19, Vite, Tailwind CSS, Recharts, Lucide Icons, motion.
- **Telegram Bot API**: Polling + WebApp интеграция.

## ⚙️ Переменные окружения (.env)

Создайте файл `.env` на основе примера `.env.example`:

```env
# Токен бота Telegram от @BotFather (например: 123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ)
TELEGRAM_BOT_TOKEN="ВАШ_TELEGRAM_BOT_TOKEN"

# Ключ Google Gemini API для умной категоризации и распознавания чеков
GEMINI_API_KEY="ВАШ_GEMINI_API_KEY"

# Публичный URL приложения (для генерации ссылок на веб-панель в боте)
APP_URL="http://localhost:3000"
```

> 🔒 **Безопасность**: Секретные ключи (`TELEGRAM_BOT_TOKEN`, `GEMINI_API_KEY`) никогда не коммитятся в репозиторий и подставляются исключительно через переменные окружения.

## 📦 Локальный запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/telegram-expense-tracker.git
cd telegram-expense-tracker
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка окружения
```bash
cp .env.example .env
# Отредактируйте .env, указав свои TELEGRAM_BOT_TOKEN и GEMINI_API_KEY
```

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Сервер запустится на `http://localhost:3000`.

### 5. Сборка для продакшена
```bash
npm run build
npm start
```

## 📱 Быстрый сценарий проверки (1 минута)

1. Откройте веб-панель или напишите в Telegram боту команду `/start`.
2. Отправьте боту сообщение: `кофе 250` или `такси 850 офис`.
3. Бот мгновенно ответит с категорией («Кафе и рестораны» / «Транспорт и авто») и кнопкой перехода в веб-панель.
4. Откройте веб-панель — трата уже отобразилась на графике за сегодня и в расходах по категориям.
5. Нажмите «Telegram-чат» в панели, чтобы протестировать быстрый ввод сообщений и команд вживую!
