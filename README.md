# 💰 Telegram Expense Tracker & Web Dashboard (Mini App)

Современный, высокопроизводительный сервис **«Трекер личных и семейных расходов в Telegram»** с поддержкой мгновенного ввода через бота, умной категоризацией, распознаванием чеков с помощью ИИ (Google Gemini AI), интерактивной веб-панелью (Telegram WebApp / Mini App) и строгой изоляцией данных пользователей.

Проект полностью настроен для локальной разработки и деплоя в один клик на **Render.com** или в **Docker**.

## 🛠 Архитектура и стек технологий

- **Backend:** Node.js, Express.js, TypeScript, tsx.
- **Telegram Bot:** Polling + Webhook API, полная поддержка команд, inline-кнопок, фото-чеков и callback-запросов.
- **Telegram WebApp Security:** Безопасная серверная валидация `window.Telegram.WebApp.initData` по алгоритму **HMAC-SHA256**.
- **AI & OCR:** Google Gemini 2.5 Flash API (@google/genai) для распознавания чеков (Alif mobi, DC Next, фискальные чеки) и категоризации.
- **Database & Data Isolation:** Локальное хранилище данных с жесткой привязкой всех записей к `userId` (`telegram_id`), сессионными токенами и поддержкой экспорта/бэкапа.
- **Frontend (WebApp):** React 19, Vite, Tailwind CSS, Recharts (диаграммы и графики), Lucide Icons, motion.
- **Сборка и продакшен:** `vite build` + `esbuild` бандлер бекенда в `dist/server.cjs` (исключает ошибки импортов на хостинге).

## 🚀 Ключевые возможности

### А. Быстрый ввод и функционал бота (Telegram Bot):
1. **Мгновенный ввод без форм:**
   - Пользователь пишет: `кофе 350`, `такси 900 работа`, `продукты 1850 супермаркет` или `қаҳва 45`, `нону шир 50`.
   - Система автоматически выделяет сумму, валюту, описание и присваивает категорию («Кафе и рестораны», «Транспорт и авто», «Продукты», «Переводы» и т.д.).
2. **Мультивалютность:**
   - Распознавание TJS (сомони), RUB (рубли), USD ($), EUR (€), KZT (тенге).
   - Пример ввода: `50$ ужин`, `150 сомони бензин`, `3000 руб подарок`.
3. **Отчеты и команды:**
   - `/today` — мгновенная сводка трат за сегодняшний день.
   - `/week` — итоги за последние 7 дней со сравнением с прошлой неделей.
   - `/month` — подробная структура трат по категориям с процентами и суммами.
   - `/days` — группировка трат по дням месяца.
   - `/history` — список последних операций с деталями.
   - `/last` и `/delete` — просмотр и удаление последней добавленной траты.
   - `/edit` — быстрый вызов меню редактирования категории и суммы.
   - `/limits` — управление месячными лимитами по категориям.
   - `/share` — генерация кода для общего семейного бюджета на двоих.
   - `/export` — мгновенная выгрузка трат в файл `.csv`.
4. **Распознавание чеков (AI OCR):**
   - Отправьте в бот фото чека из супермаркета, АЗС или скриншот перевода из мобильного банка (Alif mobi, DC Next, Сбер) — ИИ автоматически считает итоговую сумму, валюту, наименование магазина/получателя и создаст операцию.

### Б. Веб-панель (Telegram WebApp):
1. **Вход без пароля и регистрации:**
   - Открытие прямо внутри Telegram через кнопку меню бота или команду `/panel`.
   - Автоматическая бесшовная авторизация через Telegram Mini App.
2. **Интерактивный дашборд:**
   - Карточки сводки: расходы за сегодня, текущую неделю и текущий месяц.
   - **Donut Chart (Recharts):** наглядное распределение расходов по категориям с цветовой дифференциацией.
   - **Line / Bar Chart:** динамика расходов по дням месяца для выявления пиковых трат.
   - Монитор лимитов бюджета с индикацией процента исчерпания.
3. **Список операций (History) с моментальной синхронизацией:**
   - Удобная таблица и список с фильтрацией по категориям и поиском по описанию.
   - Модальное окно редактирования (сумма, категория, дата, описание).
   - Кнопка удаления с подтверждением.
4. **Адаптивность (Mobile-First):**
   - Оптимизировано под Telegram клиент на iOS и Android.
   - Telegram UX: нативные отступы, чистая типографика, плавные анимации `motion`.
5. **Экспорт в CSV:**
   - Скачивание полного отчета с поддержкой кодировки Excel (UTF-8 with BOM).

### В. Безопасность и валидация initData (HMAC-SHA256)

В `server.ts` реализована официальная валидация строки инициализации Telegram WebApp:
```ts
// secret_key = HMAC-SHA256(key="WebAppData", data=bot_token)
// calculated_hash = HMAC-SHA256(key=secret_key, data=data_check_string)
```
- Доступ к данным пользователя возможен только при совпадении криптографической подписи Telegram.
- Данные изолированы по `telegram_id`: каждый пользователь видит исключительно свои транзакции (либо совместные, если подключен партнер через `/share`).

## 📦 Локальный запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/telegram-expense-tracker.git
   cd telegram-expense-tracker
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите в режиме разработки:**
   ```bash
   npm run dev
   ```
   Сервер запустится на `http://localhost:3000`.

4. **Проверка сборки (Production Build):**
   ```bash
   npm run build
   npm start
   ```

## 🌐 Деплой на Render.com

### Вариант 1: Web Service (Node Runtime)
1. В панели Render нажмите **New +** -> **Web Service** -> выберите репозиторий.
2. Укажите параметры сервиса:
   - **Name:** `telegram-expense-tracker`
   - **Environment:** `Node`
   - **Build Command:** `npm run build`
   - **Start Command:** `npm start`
3. В разделе **Environment Variables** добавьте:
   - `TELEGRAM_BOT_TOKEN` (или `BOT_TOKEN`) = `ваш_токен_от_BotFather`
   - `GEMINI_API_KEY` = `ваш_ключ_от_Google_AI_Studio`
   - `APP_URL` = `https://ваш-сервис.onrender.com`
   - `NODE_ENV` = `production`
   - `PORT` = `3000`
4. Нажмите **Create Web Service**. Сервис автоматически соберет проект и запустит сервер и Telegram-бота!

### Вариант 2: Docker
В репозитории подготовлен `Dockerfile`. Выберите в Render тип среды **Docker** — билд и запуск пройдут автоматически.

## 🤖 Настройка WebApp в @BotFather

Чтобы кнопка Mini App появилась прямо в интерфейсе Telegram:
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Введите `/mybots` -> выберите своего бота.
3. Перейдите в **Bot Settings** -> **Menu Button** -> **Configure menu button**.
4. Отправьте URL вашей веб-панели (например, `https://spend-tracker-bot-v87h.onrender.com`).
5. Укажите название кнопки: `📊 Расходы` или `Веб-панель`.
6. Теперь внизу диалога с ботом у всех пользователей появится удобная кнопка вызова Mini App!

## 🔌 API Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/auth/telegram-webapp` | Беспарольная аутентификация через `initData` с HMAC-SHA256 валидацией |
| `GET` | `/api/me` | Данные текущего профиля и подключенного партнера |
| `GET` | `/api/expenses` | Список расходов текущего пользователя |
| `POST` | `/api/expenses` | Создание нового расхода |
| `PUT` | `/api/expenses/:id` | Редактирование существующего расхода |
| `DELETE` | `/api/expenses/:id` | Удаление расхода |
| `GET` | `/api/stats` | Агрегированная статистика (день, неделя, месяц, по категориям) |
| `POST` | `/api/receipt-scan` | Распознавание чека через Gemini OCR |
| `GET` | `/api/export-csv` | Экспорт расходов пользователя в CSV (UTF-8 BOM) |
| `POST` | `/api/telegram/webhook` | Эндпоинт для приема вебхуков Telegram |
| `GET` | `/api/bot-status` | Статус соединения с Telegram Bot API |
